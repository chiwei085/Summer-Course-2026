0. Shared Foundation: Grayscale & Image Gradients

Every detector below starts the same way: convert to grayscale (BT.601 luma), then convolve with the 3×3 Sobel kernels to get the local gradient . Magnitude tells you how strongly the image is changing at a pixel; orientation tells you the direction of steepest change (perpendicular to any edge running through that pixel). Edge, corner, and line detection all reuse exactly this gradient field — nothing below this cell recomputes it from scratch.

1. Edge Detection — Canny

Canny thins the gradient magnitude to single-pixel ridges with non-max suppression along the gradient direction, then keeps a pixel as an edge if it clears high, or clears low and is 8-connected (through other weak pixels) to one that clears high — hysteresis. Drag the thresholds and watch edges appear/disappear/reconnect.

high < low is degenerate (nothing ever seeds hysteresis) — the backend doesn't reorder them for you, so you can see that failure mode directly.

2. Corner Detection — Harris

At every pixel, sum Ix², Iy², IxIy over a window to build the structure tensor M, then look at its eigenvalues λ1, λ2 — the amount the local gradient varies along the two directions that diagonalize M. Harris response R is a fast, eigenvalue-free proxy for the same classification. Non-max suppression then picks isolated peaks. Click a corner marker to read its response.

3. Line Detection — Hough Transform

Every Canny edge pixel votes, for each candidate angle θ, into an accumulator cell — a line's worth of collinear points all vote into the same (ρ, θ) cell, so it becomes a peak. Cells clearing the vote threshold become lines (kept only if far enough from every line already kept, in both ρ and θ); edge points near each line are then projected onto it and split into segments wherever there's a gap, so only real line segments get drawn, not the infinite line.
