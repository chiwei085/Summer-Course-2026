2. Histogram

Each panel has 256 bins, one per 8-bit value 0–255. A bin's height is the count of pixels whose value landed in it — hover a panel to read a bin's exact value and count. Sample a pixel in cell 1 to see its value marked here.

Intensity isn't captured by the camera like R, G, B — it's computed from them (see the method picker in cell 1). Its panel is dashed to mark that difference.

A histogram throws away where pixels are

Shuffling every pixel's position produces a completely different-looking image with the exact same histogram — counting values doesn't care about their arrangement.
